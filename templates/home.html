Welcome to the Breast Cancer Classification

This application helps you classify breast cancer cases as benign or malignant based on input features.

Before classifying, let's understand the types and characteristics of benign and malignant tumors.

Benign Tumor

Definition: A benign tumor is a non-cancerous growth that does not spread to other tissues or organs.

Characteristics:

  • Grows slowly
  • Has clear boundaries
  • Generally not life-threatening

Malignant Tumor

Definition: A malignant tumor is a cancerous growth that can invade and destroy surrounding tissue and spread to other parts of the body.

Characteristics:

  • Grows quickly and aggressively
  • Has unclear boundaries
  • Can be life-threatening

Did You Know?

Breast cancer is one of the most common types of cancer, affecting millions of people worldwide. Early detection and accurate classification of tumors can greatly improve treatment outcomes.

This application utilizes machine learning techniques to help classify tumors based on specific input features, allowing for a more informed diagnostic approach.

About

This is an application to assist with breast cancer classification. This application was developed using the Naive Bayes algorithm with hyperparameter optimization through RandomizedSearchCV, achieving a classification accuracy of up to 94.74%.

Tutorial

Enter values for the following features to perform classification:

  • Radius Mean: Enter a value between 6.0 - 30.0
  • Texture Mean: Enter a value between 10.0 - 40.0
  • Perimeter Mean: Enter a value between 40.0 - 190.0
  • Area Mean: Enter a value between 150.0 - 2500.0
  • Smoothness Mean: Enter a value between 0.05 - 0.15
  • Compactness Mean: Enter a value between 0.02 - 0.35
  • Concavity Mean: Enter a value between 0.01 - 0.40
  • Concave Points Mean: Enter a value between 0.01 - 0.20
  • Symmetry Mean: Enter a value between 0.10 - 0.30
  • Fractal Dimension Mean: Enter a value between 0.05 - 0.10

Once all values are entered, click the Classify button to see the diagnosis result.
